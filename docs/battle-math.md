# 战斗运算逻辑（数学规格）

本文档从纯数学角度描述战斗系统的运算规则与 AI 决策逻辑，不涉及代码文件、内存地址、数据结构或修改指引等工程细节，可作为任何实现的规则依据。它是 `docs/battle-logic.md`（工程实现参考）的规则提取版：需要工程信息时看实现参考，需要纯规则描述时读本文。

文中所有变量均为整数，符号定义见第 1 节。

## 1. 记号与基本语义

### 1.1 整数语义

- 中间结果按 16 位有符号整数回绕（模 65536）。
- 除法一律向零取整。

### 1.2 随机数

随机序列由线性同余生成器产生：

```text
seed = seed × 0x41C64E6D + 0x3039   （模 2^32）
rand() = (seed >> 16) & 0x7FFF
```

取随机范围的包装函数：

```text
rnd(n) = 0             当 n ≤ 1 或 n > 30000，且不推进随机序列
rnd(n) = rand() mod n  其余情况，取值 0..n-1，推进一次随机序列
```

「不推进随机序列」的意思是：随机数的消耗次数随参数取值而变化。所有规则共用同一随机序列，随机调用的**次数、顺序与取值范围**共同决定后续结果，因此各公式的执行顺序会直接影响之后的随机结果。

### 1.3 基础属性

| 类别 | 记号 | 含义 |
| --- | --- | --- |
| 角色状态 | `hp`、`maxHp`、`hurt`、`poisoned`、`stamina`、`mp`、`maxMp`、`level`、`exp` | 生命、生命上限、受伤值、中毒值、体力、内力、内力上限、等级、经验 |
| 角色属性 | `attack`、`speed`、`defence` | 攻击、速度、防御 |
| 角色属性 | `medic`、`poison`、`depoison`、`antipoison` | 医疗、用毒、解毒、抗毒熟练度 |
| 角色属性 | `fist`、`sword`、`blade`、`special`、`throwing` | 拳、剑、刀、特殊、暗器熟练度（上限 100） |
| 角色属性 | `knowledge`、`integrity`、`poisonAmp`、`doubleAttack`、`potential` | 知识、性格（正邪）、毒力加成、双击（1 为可双击）、资质 |
| 角色装备 | `equip[2]` | 两件装备，各自的 `addAttack`、`addSpeed`、`addDefence` 参与计算 |
| 角色武功 | `skillId[10]`、`skillLevel[10]` | 至多 10 门武功及其熟练度 |
| 武功 | `reqMp`、`addPoison`、`skillType`、`attackAreaType`、`damageType` | 需求内力、附加毒、武功类型、作用范围类型、伤害类型 |
| 武功 | `damage[10]`、`selRange[10]`、`area[10]`、`addMp[10]`、`drainMp[10]` | 按等级排列的伤害、射程、范围半径、吸内力、耗内力 |
| 物品 | `addHp`、`addMp`、`addPoisoned`、`addAttack`、`addSpeed`、`addDefence`、`throwingEffectId`、`itemType` | 物品效果字段（攻击类暗器 `addHp` 为负数） |

### 1.4 武功等级

`skillLevel` 是 0..999 的原始值，**等级** = `skillLevel / 100`，取值 0..9。要注意区分「原始等级」与「按内力降级后的等级」：不同规则各自选用（见 5.1、5.5、5.7）。

## 2. 战斗流程

### 2.1 回合循环

```text
每回合：
  1. 重排行动顺序
  2. 为每个参与者重算移动步数
  3. 按顺序派发行动，逐个执行
  4. 队列清空后（首个回合除外）对所有参与者结算受伤与中毒
  5. 进入下一回合
```

### 2.2 行动顺序

排序键为 `speed + 武器 addSpeed + 防具 addSpeed`，按降序排列。算法按槽位逐个扫描，与后续每一个参与者比较，发现更快的立即交换；这个「即时交换」方式决定了速度相同者之间的先后顺序，结果未必与稳定排序一致。

### 2.3 移动步数

```text
steps = max(0, (speed + 武器 addSpeed + 防具 addSpeed) / 15 - hurt / 40)
```

`steps` 为 0 时角色本回合无法移动。

### 2.4 等待

把当前行动者与后续参与者依次交换，相当于移到队尾，本轮最后再行动。

### 2.5 回合末结算

```text
对每个参与者：
  执行条件：hurt > 0；或 poisoned > 0 且 stamina > 0 且未退场
  执行内容：
    hp      -= hurt / 20
    hp      -= poisoned / 10
    stamina < 0  → 1
    hp      < 0  → 1
```

### 2.6 胜负判定

每次行动结束后运行：

```text
1. hp <= 0 且未退场者：清空所占格子，置退场标记
2. 统计双方是否还有在场者
3. 己方全灭 → 失败；敌方全灭 → 胜利；两者同时成立时结果为胜利
```

## 3. 玩家行动菜单

体力比较全部为严格大于（阈值不含等号）。

| 菜单项 | 开放条件 |
| --- | --- |
| 移动 | `stamina > 5` 且剩余步数 > 0 |
| 武功 | `stamina > 10` 且 `mp >= 已学武功中最小的 reqMp` |
| 用毒 | `stamina > 10` 且 `poison >= 20` |
| 解毒 | `stamina > 50` 且 `depoison >= 20` |
| 医疗 | `stamina > 50` 且 `medic >= 20` |
| 物品、等待、状态、休息、自动 | 始终开放 |

## 4. 数值公式

### 4.1 武功等级与内力消耗

```text
内力消耗：cost(level) = reqMp × ((level + 1) / 2)     level 从 0 起
可用等级：从 skillLevel / 100 递减，取第一个满足 mp >= cost(level) 的等级
```

`level = 0` 的消耗为 0，因此内力耗尽时武功仍可在最低等级施放。内力在**每次攻击**扣除一次，不按受击目标逐个扣除（区域武功打中多个目标也只扣一份）。

### 4.2 实际攻击与实际防御

```text
实际攻击 = (attack × 3 + skill.damage[level]) / 2
         + 武器 addAttack + 防具 addAttack
         + 兵器绑定加成
         + 己方知识项

实际防御 = defence + 防具 addDefence + 武器 addDefence + 对方知识项
```

`attack` 与 `defence` 取**不含装备**的角色基础值。

- 兵器绑定：装备 `equip[0]` 的 id 与武功 id 同时匹配时，把该项加成计入实际攻击。
- 知识项：遍历全部参与者，满足 `knowledge > 80`（不含等号）、`hp > 0`、未退场者才参与；与**攻击方**同阵营的计入攻击项，其余计入防御项，累加值均为 `knowledge × 2`。阵营相对攻击方判定，敌方攻击时两项互换。

### 4.3 伤害

```text
dmg = (实际攻击 - 实际防御 × 3) × 2 / 3
dmg += rnd(20)
dmg -= rnd(20)
若 dmg <= 0：
    dmg = 实际攻击 / 10
    dmg += rnd(4)
    dmg -= rnd(4)
若 dmg < 0：
    dmg = 0                     并跳过后续加成
否则：
    dmg += 攻击方 stamina / 15
    dmg += 目标 hurt / 20
    dmg = 距离衰减(dmg, 距离)
dmg = max(dmg, 1)
```

要点：

- 随机消耗是 2 次或 4 次，取决于是否走回退分支。
- `dmg == 0` 仍继续执行体力、受伤与距离衰减，只有 `dmg < 0` 才跳过后续加成。
- 下限钳制在**距离衰减之后**，因此 1 点伤害经远距离衰减后仍是 1。

### 4.4 距离衰减

```text
距离 > 10：dmg = dmg × 2 / 3
否则：     dmg = dmg × (100 - (距离 - 1) × 3) / 100
```

衰减**无条件执行**。距离 1 的系数是 100%，距离 0 的系数是 103%。

### 4.5 命中后的状态变化

```text
经验：攻击方 exp += dmg / 5
击杀：目标 hp - dmg 严格小于 0 时，攻击方 exp += 目标 level × 10
受伤：目标 hurt += dmg / 10，上限 99
中毒：
    毒力 = (skillLevel / 100 + 1) × skill.addPoison + 攻击方 poisonAmp
    毒力 > 目标 antipoison 且目标 antipoison < 90 时：
        目标 poisoned += (毒力 - antipoison) / 15
```

中毒一步用的是**未经内力降级的原始等级**，与伤害用的等级可能不同；目标已阵亡时同样执行。击杀奖励只在「过量击杀」时给出，即伤害严格超过剩余生命。

### 4.6 熟练度与体力

```text
双击次数：doubleAttack == 1 时为 2，否则为 1；多次攻击共用同一目标
熟练度：  每次攻击 skillLevel += rnd(2) + 1，上限 999，升级时保留余量
体力：    全部攻击次数结束后统一扣 3
```

### 4.7 吸内力

`skill.damageType > 0` 的武功走这条分支，使用**原始等级**：

```text
施放者 mp    += skill.addMp[等级]
施放者 maxMp += rnd(skill.addMp[等级] / 2)               上限 999
施放者 mp    += rnd(3) - rnd(3)                          然后钳制到 maxMp
目标   mp    -= skill.drainMp[等级] + rnd(3) - rnd(3)    下限 0
返回值 = 目标实际损失的内力
```

施放者的收益与目标的损失**互不相关**，且会永久提升内力上限。这条分支不给经验。

### 4.8 辅助行动

作用范围一律是 `对应熟练度 / 15 + 1`。

| 行动 | 公式 | 体力 | 经验 |
| --- | --- | ---: | ---: |
| 用毒 | `(poison - antipoison) / 4`，钳制 0..99 | 2 | 1 |
| 解毒 | `depoison / 3 + rnd(10) - rnd(10)`，钳制 0..99；目标 `poisoned > depoison + 20` 时归零；不超过目标当前中毒值 | 2 | 1 |
| 医疗 | `hurt <= 25` 取 `medic × 4 / 5`，`<= 50` 取 `medic × 3 / 4`，`<= 75` 取 `medic × 2 / 3`，否则 `medic / 2`，再 `+ rnd(5)`；同时 `hurt -= medic` | 4 | 1 |
| 暗器 | 见 4.9 | 0 | 0 |
| 休息 | 见 4.10 | — | 0 |

- 用毒返回实际增加的中毒值（正数），解毒返回实际减少量（正数）。
- 医疗的「`hurt > medic + 20` 则拒绝治疗」判定在随机数抽取**之后**生效，此时治疗量与受伤削减同时归零，但随机数已经消耗。
- 医疗的 4 点体力 = 行动内部 2 点 + 三项辅助行动的公共尾段 2 点；公共尾段同时给 1 点经验，无论行动是否生效都会执行。

### 4.9 暗器

```text
按目标受伤分档取基数：
    hurt == 0  → addHp / 4
    hurt <= 33 → addHp / 3
    hurt <= 66 → addHp / 2
    否则       → addHp
基数 -= rnd(5)
delta = (基数 - 施放者 throwing × 2) / 3

目标 hurt -= delta / 4    钳制 0..99
目标 hp   += delta        钳制 0..maxHp
```

`addHp` 是物品原始值，攻击类暗器为负数，`delta` 随之也为负，扣血的同时抬高受伤值。暗器**没有最低 1 点伤害**的下限。四个分档都消耗一次 `rnd(5)`。

附加毒性：

```text
addPoisoned > 0：
    目标 antipoison >= 100 → 0
    否则 目标 poisoned += max(0, (addPoisoned - 施放者 throwing) / 2 - antipoison) / 2
addPoisoned <= 0：
    目标 poisoned += addPoisoned / 2 + rnd(5) - rnd(5)
```

毒性分支不消耗随机数，解毒分支消耗两次。

### 4.10 休息

```text
stamina += rnd(3) + (本回合已移动 ? 2 : 3)      上限 100
新 stamina >= 30 时：
    hp += rnd(新 stamina / 10 - 2) + 3          上限 maxHp
    mp += rnd(新 stamina / 10 - 2) + 3          上限 maxMp
```

`rnd` 的参数可能退化到 0 或 1，此时不消耗随机数且返回 0，恢复量固定为 3。「已移动」按本回合实际发放的步数判断：步数全部用完即视为移动过。

### 4.11 升级

一次结算全部等级差 `n`，不逐级循环。

```text
成长系数：factor = rnd(档位) + 1
    potential < 30 → 档位 2
    potential < 50 → 档位 3
    potential < 70 → 档位 4
    potential < 90 → 档位 5
    否则           → 档位 6

maxHp += n × 3 × (hpAddOnLevelUp + rnd(3))       上限 999
随后 hp 回满、hurt 与 poisoned 清零、stamina 置 100
maxMp += n × 4 × (9 - factor)                    上限 999
随后 mp 回满
attack、speed、defence += n × factor             各自上限 100

medic、poison、depoison、fist、sword、blade：值 > 20 时各 += rnd(3)
throwing：无条件 += rnd(3)
special：不成长
上述熟练度上限均为 100
```

随机消耗顺序：成长系数 1 次，`maxHp` 的 `rnd(3)` 1 次，六项熟练度按 medic、poison、depoison、fist、sword、blade 的顺序（各自满足条件时），最后 throwing 1 次。

## 5. 范围与目标

### 5.1 距离网格

攻击范围与目标选择基于一张距离图（由洪泛扩散生成，下称洪泛距离）：自身格为 0，向四邻逐格扩散，绕开阻挡格（建筑与不可通行地形），**不受角色占位影响**。各步代价相同，因此距离对称，从目标格扩散一次即可得到任意候选格的距离。

- 目标选择的距离上限**包含等号**：`距离 <= 范围` 即可选中。
- 移动可达格另按受角色占位阻挡的路径计算，与上述距离图不同。

### 5.2 四种作用范围

| `attackAreaType` | 形状 | 遍历顺序 | 距离取法 |
| ---: | --- | --- | --- |
| 0 | 单体 | 仅光标格 | 施放者到目标格的曼哈顿距离 |
| 1 | 直线 | 朝向固定，步距由 1 递增到 `selRange[level]` | 步距本身 |
| 2 | 十字 | 步距由 1 递增，每步按上、下、左、右四方向 | 步距本身 |
| 3 | 区域 | 以光标为中心、半径 `area[level]` 的方形，先列后行 | 施放者到**实际命中格**的曼哈顿距离 |

要点：

- 直线与十字都是由近及远遍历，随机数消耗顺序随之固定。
- 十字的四方向顺序是上、下、左、右。
- 区域武功的距离不是「光标距离 + 偏移」，而是每格单独计算。
- 直线武功不因中途有目标而中断。
- 目标选择范围用 `selRange[level]`，区域武功的伤害半径用 `area[level]`。
- 单体与区域武功只在第一次攻击时选目标，双击的第二次沿用同一目标。

### 5.3 辅助行动的范围

用毒、解毒、医疗、暗器的可选距离都是 `对应熟练度 / 15 + 1`。

## 6. AI 逻辑

AI 分三段：**决定做什么**（决策级联）、**决定打谁**（目标选择）、**怎么走过去并执行**（站位与移动）。

决策所需信息：角色属性（含已学武功中最小的 `reqMp`，没有武功时为空）、阵营、是否在场（`hp > 0` 且未退场）、求助标记、到行动者的洪泛距离（不可达视为不可选）、可用物品（己方取共享行囊，敌方取角色自带的 4 格，装备与武功书不参与）。

### 6.1 决策级联

八级按顺序执行，任一级产生行动即停止。级联的随机消耗顺序必须与下表一致。

| 级 | 触发条件 | 结果 |
| ---: | --- | --- |
| 1 | `stamina < 10` | 休息 |
| 2 | `hp < 20` 或 `hurt > 50` 或（`hp < maxHp/2` 且 `rnd(10) < 3`）或（`hp < maxHp/3` 且 `rnd(10) < 5`）或（`hp < maxHp/4` 且 `rnd(10) < 7`）或（`hp < maxHp/5` 且 `rnd(10) < 9`） | 走补血流程（6.2） |
| 3 | `rnd(10) < poisoned / 10`（无条件抽取） | 走解毒流程（6.2） |
| 4 | （`mp < maxHp/2` 且 `rnd(10) < 2`）或（`mp < maxHp/3` 且 `rnd(10) < 4`）或（`mp < maxHp/4` 且 `rnd(10) < 6`）或（`mp < maxHp/5` 且 `rnd(10) < 8`） | 找 `addMp > 0` 的物品 |
| 5 | `stamina > 50` 且（`medic >= 20` 且 `rnd(10) < 4`）或（`medic >= 40` 且 `rnd(10) < 6`）或（`medic >= 60` 且 `rnd(10) < 8`）或 `medic >= 80` | 为友方医疗（6.3） |
| 6 | `stamina > 50` 且 `depoison` 满足同型四段阈值 | 为友方解毒（6.3） |
| 7 | `rnd(10) < 5` 且（`hp < 20` 或（`hp < maxHp/4` 且 `rnd(10) < 6`）或（`hp < maxHp/5` 且 `rnd(10) < 8`）） | 逃跑 |
| 8 | 其余 | 行动选择（6.4） |

第 1 级不消耗随机数。第 2 级与第 7 级的条件按顺序逐个判断，前面条件成立时，后面的随机数不再抽取。

### 6.2 自救与求助

补血流程分三级：

```text
1. medic >= 20 且 stamina >= 50 且 medic > hurt - 30      → 对自己医疗
2. 物品中存在 addHp > 0                                   → 使用该物品
3. 存在同阵营在场友方，medic > 20 且 medic > 我的 hurt - 30 → 登记求医标记，本回合照常攻击
```

解毒流程结构相同，判据换成 `depoison` 与 `poisoned`，物品判据是 `addPoisoned < 0`。补内力只有一步：找 `addMp > 0` 的物品。

求助标记记在行动者自己身上；之后行动的友方若具备对应熟练度，看到标记会跳过全部概率门直接施救。标记在角色自己下次行动开始时清零，因此可以跨回合保留到该角色再次行动之前。

### 6.3 为友方医疗与解毒

按参与者下标顺序取**第一个**满足条件者，不选「最严重」的：

```text
医疗：前置 我的 medic > 对方 hurt - 30
      条件 对方已登记求医标记
        或 hp < 20
        或 hurt > 40
        或（hp < maxHp/2 且 rnd(10) < 7）
        或（hp < maxHp/3 且 rnd(10) < 8）
        或（hp < maxHp/4 且 rnd(10) < 9）
        或 hp < maxHp/5

解毒：前置 我的 depoison > 对方 poisoned - 30
      条件 对方已登记求解标记
        或（poisoned > 10 且 rnd(10) < 4）
        或（poisoned > 20 且 rnd(10) < 6）
        或（poisoned > 30 且 rnd(10) < 8）
        或 poisoned > 40
```

### 6.4 行动选择

```text
1. 战力对比转辅助：
     敌方战力均值 / 2 > 我的 hp + attack
     且 己方战力总和 > 敌方战力总和 × 2
   成立时：
     medic >= 20 且 stamina >= 50        → 医疗生命缺口最大的友方
     否则 depoison >= 20 且 stamina >= 50 → 为中毒值最高的友方解毒
   战力 = 该阵营全部参与者的 attack + hp 之和，统计时包含不在场者

2. 用毒：poison - attack > rnd(50) 且 rnd(150) < poison

3. 投掷：扫描物品
     己方：|addHp| > attack × 3 / 2 且 rnd(throwing) > 20
     敌方：|addHp| > attack 且 rnd(10) < 6
     毒性物品：addPoisoned > 同一门槛 且 rnd(10) < 3

4. 普通攻击：stamina > 10 且 mp >= 已学武功中最小的 reqMp

5. 以上都不成立 → 休息
```

### 6.5 目标选择

按人物性格分流，各有 70% 触发率（`rnd(10) < 7`），依次尝试：

| 条件 | 选择 |
| --- | --- |
| `integrity >= 75` 且 `rnd(10) < 7` | 攻击最高的在场敌人 |
| `integrity <= 25` 且 `rnd(10) < 7` | 攻击最低的在场敌人 |
| `potential >= 70` 且 `rnd(10) < 7` | 敌方辅助：己方有 `poison > 20` 者时取解毒最高的敌人，否则取医疗最高的敌人，均要求该熟练度 >= 20；都不满足时退回「攻击最低」 |
| 其余 | 洪泛距离最近的在场敌人 |

用毒目标另有一套，只考虑 `poisoned < 95` 且 `antipoison < 我方 poison` 的在场敌人：`potential > 60` 且 `rnd(10) < 7` 时取攻击最高者，否则取距离最近者。

### 6.6 攻击执行

```text
1. 在 skillId > 0 的槽位中随机选一门（不做伤害评估）
2. 取等级、射程 selRange[level]、作用范围类型
3. 按 6.5 取目标
4. 判定能否命中：
     范围类型 0 或 3：距离 <= 射程
     范围类型 1 或 2：距离 <= 射程 且 与目标同排或同列
5. 能命中 → 出手
   否则：剩余步数 > 0 时移动（见下），移动后重判
   仍不能命中 → 改取最近的敌人重判
   仍不能命中 → 休息
```

### 6.7 移动

- 进攻站位：从射程上限向下枚举期望距离 `r`，在本回合走得到的格子中找洪泛距离恰好为 `r` 的格子（直线与十字还要求与目标同排同列），取离当前位置曼哈顿距离最小的一格；以第一个找到候选格的 `r` 为准。效果是「尽量保持武功允许的最大距离，且少走路」。
- 撤退站位（逃跑与用物品前）：只在**恰好用尽全部移动力**的格子中挑选，取与敌方各角色曼哈顿距离之和最大的一格。逃跑后休息，用物品前的撤退不休息。

### 6.8 动作集与回退

AI 的动作集：休息、攻击、用毒、解毒、医疗、用物品、投掷、逃跑。辅助行动无法送达时（目标不可达）按以下规则回退：

```text
attack × 2 > 己方战力总和 × 2 / 人数 → 改为攻击
否则                                  → 休息
```

## 7. 战后结算

### 7.1 结算顺序

```text
1. 敌方角色 hp 与 mp 回满，stamina 置 100，hurt 与 poisoned 清零
2. 胜利时：把 战场经验 / 存活人数 加到每个存活的己方角色
3. 己方存活者 hp 不低于 maxHp / 5
   己方倒下者 hp 置 maxHp / 5，stamina 不低于 10
4. 对每个角色（不看胜负）：
     exp            += 本场经验
     expForItem     += 本场经验 × 8 / 10
     expForMakeItem += 本场经验 × 8 / 10
     三者上限 60000
5. 胜利或「失败也给经验」开关打开时，才显示经验提示并依次执行升级、练功、制药
```

第 4 步的三项经验各自独立累加，不是在「升级」与「练功」之间二选一。

### 7.2 升级

见 4.11。先算出等级差 `n`，再一次性结算，不能在循环里反复执行。

### 7.3 资质档位

练功与制药共用同一个档位：

```text
tier = 7 - potential / 15     不做钳制，取值范围 1..7
```

资质越高档位越小，需要的经验越少。

### 7.4 练功

```text
tier = 7 - potential / 15
若 item.skillId != -1（武功书）：
    level = 该武功在角色身上的当前等级（未学得时为 0）
    need  = (level + 1) × item.reqExp × tier
    level >= 9 时整步跳过
否则（纯属性书）：
    need = item.reqExp × tier × 2

learningItem == -1 时跳过
expForItem < need 时跳过

执行内容（每场战斗最多一次）：
    套用书本属性（见下）
    expForItem = 0
    若 item.skillId > 0：
        已学得该武功 → 存储值 < 899 时 skillLevel += 100
        未学得       → 放进第一个空槽位，等级不变
```

要点：

- **每场战斗只推进一次**，不循环。
- `expForItem` 直接**清零**，不是减去 `need`，超出部分不保留。
- 升级是 `+= 100`，余量随之带入下一级，不做取整。
- 全程**不消耗随机数**，也没有内力上限的随机加成。

书本属性套用是一套独立规则，按下列顺序执行 19 项：

| 物品字段 | 目标 | 规则 |
| --- | --- | --- |
| `addMaxHp` | `maxHp` | `+=`，只有上限 999，没有下限 |
| `changeMpType` | `mpType` | 仅当 `changeMpType == 2` 时把 `mpType` 置 2，其他取值不动 |
| `addMaxMp` | `maxMp` | `+=`，只有上限 999，没有下限 |
| `addAttack` … `addIntegrity` | `attack`、`speed`、`defence`、`medic`、`poison`、`depoison`、`antipoison`、`fist`、`sword`、`blade`、`special`、`throwing`、`knowledge`、`integrity` | `+=` 后钳进 0..100，先判上限，再判下限 |
| `addDoubleAttack` | `doubleAttack` | 仅当角色当前为 0 时**赋值**（不是相加） |
| `addPoisonAmp` | `poisonAmp` | `+=` 后钳进 0..100 |

`addHp`、`addMp`、`addPoisoned`、`addStamina` 这四个消耗品字段**完全不套用**。

### 7.5 制药

```text
need = item.reqExpForMakeItem × tier
reqExpForMakeItem <= 0 或 expForMakeItem < need 时跳过

材料数量 = 行囊中 item.reqMaterial 的数量
候选配方 = { k | 材料数量 > 0 且 item.makeItem[k] >= 0 且 材料数量 >= item.makeItemCount[k] }
候选为空时跳过

反复 rnd(5) 直到落在候选上，得到 pick
产出数量 = 行囊中已有该产物 ? rnd(3) + 1 : 1
行囊 += (item.makeItem[pick], 产出数量)
行囊 -= (item.reqMaterial, item.makeItemCount[pick])
expForMakeItem = 0
```

要点：

- `makeItemCount[k]` 是该配方**消耗的材料数量**，不是产出数量。
- 产出数量在「行囊已有该物品」与「新开格子」两种情况下不一致。
- 抽取范围是全部 5 个配方槽位，不限于排在前面的几个。
- 只有己方角色制药。
