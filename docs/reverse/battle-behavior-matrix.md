## 修复候选

以下问题来自当前 C++ 实现，只能在对应原版控制流确认后标记为「修正版差异」：

- 敌方攻击时知识加成索引可能使用了玩家侧数据。
- AI 预测防御可能没有使用完整的知识修正。
- 攻击附加中毒的返回值符号可能与界面语义相反。
- `x == 0` 的死亡角色可能没有清理格子占位。
- 自动使用物品前的移动目标可能选择了相反的距离方向。
